# Fundamentos de JavaScript

Este repositório contém exercícios desenvolvidos durante as aulas da disciplina
**Práticas de Programação**, com foco em lógica de programação e fundamentos de JavaScript.

## Conteúdos abordados
- Variáveis (`let` e `const`)
- Entrada de dados com `prompt`
- Saída de dados com `console.log` e `alert`
- Operadores aritméticos e relacionais
- Estrutura de decisão `if / else`

## Exercício disponível
- **Cálculo de média escolar**
  - Entrada de quatro notas
  - Cálculo da média
  - Verificação de aprovação, recuperação ou reprovação usando `if / else`

## Objetivo
Praticar a lógica de programação e compreender o funcionamento básico das estruturas condicionais em JavaScript.

## Observações
Projeto desenvolvido para fins acadêmicos e de aprendizado.
